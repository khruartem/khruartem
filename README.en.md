### [Есенин. Жизнь в стихах](https://esenin-play.otkter.ru)

Website for the musical and poetic performance «Есенин. Жизнь в стихах» by «Открытая Территория». It includes information about the performance and cast, a full-screen photo gallery, media publications, SEO metadata, and structured event data.

Client-side interactivity is implemented in TypeScript without a UI framework, with separate model, controllers, and view layers connected through a typed event bus.

**Stack:** Astro, TypeScript, Tailwind CSS, Astro Image, GitHub Actions
[Website](https://esenin-play.otkter.ru) · [GitHub](https://github.com/khruartem/otkter-esenin)
