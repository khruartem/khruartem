## Избранные проекты

### [Открытая Территория](https://otkter.ru)

Production-сайт творческого объединения «Открытая Территория». Разрабатываю и поддерживаю проект полного цикла: от реализации интерфейсов по Figma и архитектуры frontend-приложения до интеграции с API, деплоя и дальнейшего развития.

**Стек:** React, TypeScript, Redux Toolkit, React Router, SCSS, REST API, Vite
[Сайт](https://otkter.ru) · [GitHub](https://github.com/khruartem/otkter)

### [Есенин. Жизнь в стихах](https://esenin-play.otkter.ru)

Сайт музыкально-поэтического спектакля творческого объединения «Открытая Территория». Включает информацию о постановке и участниках, фотогалерею с модальным просмотром, публикации в СМИ, SEO и структурированные данные события.

Клиентская интерактивность построена на TypeScript без UI-фреймворков с разделением модели, контроллеров, представления и коммуникацией через типизированный брокер событий.

**Стек:** Astro, TypeScript, Tailwind CSS, Astro Image, GitHub Actions
[Сайт](https://esenin-play.otkter.ru) · [GitHub](https://github.com/khruartem/otkter-esenin)
